## Опис завдання
C++ програма з модульною архітектурою для захоплення та обробки відеопотоку з веб-камери в режимі реального часу. 
Реалізовані модулі: `CameraProvider`, `KeyProcessor`, `FrameProcessor`, `Display`.
Доступні режими обробки (перемикання клавішами 1-5):
1. **Normal** - оригінальне зображення.
2. **Invert** - інверсія кольорів (`cv::bitwise_not`).
3. **Blur** - розмиття за Гаусом.
4. **Canny** - виділення меж.
5. **Glitch** - ефект розсування RGB каналів.

Присутній інтерактивний UI (слайдер налаштування яскравості).
