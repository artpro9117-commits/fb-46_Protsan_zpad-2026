## Опис завдання
Метою роботи є очищення даних (Data Cleaning) та побудова графіків для багатовимірного аналізу. Для виконання обрано датасет Automobile Data Set з репозиторію UCI, який містить категоріальні, цілі та дійсні атрибути, а також пропущені значення. 

За допомогою бібліотек `matplotlib` та `seaborn` побудовано 6 графіків, серед яких:
* Регресійний аналіз залежності ціни від об'єму двигуна.
* Гістограма розподілу потужності за 5 заданими діапазонами.
* Багатовимірний Bubble Chart (відображення 4 вимірів одночасно).
* Графіки розмаху (Boxplot), стовпчикові діаграми та теплова карта кореляції.
