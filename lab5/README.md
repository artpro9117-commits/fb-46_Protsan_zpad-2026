## Опис завдання
Розроблено інтерактивний веб-додаток на базі фреймворку `Streamlit` для аналізу та візуалізації вегетаційних індексів (VCI, TCI, VHI) з лабораторної роботи №2.
Функціонал додатку:
* Випадаючі списки для вибору області та індексу.
* Слайдери для налаштування часових інтервалів (роки, тижні).
* Чекбокси для сортування датафрейму (зростання/спадання).
* Кнопка очищення фільтрів.
* Відображення результатів у 3 вкладках: сирі дані (DataFrame), лінійний графік динаміки (`plotly`) та гістограма порівняння середніх значень між усіма областями.

## Інструкція з налаштування та запуску
1. Розмістіть завантажені `.csv` файли з даними NOAA у директорію `data/` в корені проєкту.
2. Встановіть залежності:
    pip install streamlit pandas plotly
3. Запустіть сервер Streamlit:
    streamlit run app.py
