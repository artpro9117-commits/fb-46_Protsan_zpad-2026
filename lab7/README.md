## Опис архітектури (Рівень 2: Async DNN Inference)
Програму з Лабораторної №6 розширено для виконання асинхронної детекції облич за допомогою нейромережі ResNet-10 (модуль `cv::dnn`). Вирішено проблему блокування інтерфейсу важкими обчисленнями:
1. **Main Thread (UI):** Відповідає за захоплення відео з камери (`cv::VideoCapture`), відмальовування рамок і обробку клавіатури. Частота кадрів залишається стабільною (30 FPS).
2. **Worker Thread (`FaceDetector`):** Виділений потік `std::thread`, який виконує інференс нейромережі (`net.forward()`).
3. **Синхронізація:** Обмін даними між потоками (передача кадрів та отримання координат облич) захищено за допомогою `std::mutex`. Потік засинає через `std::condition_variable`, коли немає нових кадрів. 

Увімкнення режиму детекції облич здійснюється клавішею `F`.

## Вимоги до ОС та компілятора 
ОС: Linux (Ubuntu, Debian, Kali тощо)
Стандарт мови: C++17
Компілятор: GCC 7.0+ (або Clang 5.0+)
Система збірки: CMake 3.10+, Make
Бібліотеки (пакети): libopencv-dev (OpenCV 4.6.0+), POSIX Threads (pthread)
