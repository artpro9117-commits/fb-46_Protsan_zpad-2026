## Опис завдання
Розроблено програму з інтерактивним графічним інтерфейсом для малювання функції гармоніки з накладеним шумом. Використано модуль `matplotlib.widgets`. 
Реалізовано:
* Слайдери для зміни параметрів гармоніки (амплітуда, частота, фаза) та шуму (середнє, дисперсія).
* Згладжування зашумленого сигналу за допомогою IIR фільтра Баттерворта (`scipy.signal`).
* Чекбокси для перемикання видимості ліній та кнопку "Reset" для скидання параметрів.

   pip install numpy matplotlib scipy ipympl jupyter
